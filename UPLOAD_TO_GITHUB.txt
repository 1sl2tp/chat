TAPHOA CHAT — GITHUB MAIN READY

1. Giải nén ZIP.
2. Trong repo 1sl2tp/chat, xóa source/UI legacy cũ nhưng giữ lịch sử Git.
3. Chép TOÀN BỘ nội dung thư mục này vào root repo.
4. Commit lên branch main.
5. GitHub Actions pages.yml sẽ typecheck + test + Vite build trước khi deploy Pages.

GitHub Actions cần browser config (không phải service-role):
- VITE_SUPABASE_URL
- VITE_SUPABASE_PUBLISHABLE_KEY
Workflow đọc từ Repository Variables hoặc Secrets và sẽ FAIL thay vì chạy mock nếu thiếu.

Không upload các thư mục sinh tự động: node_modules, dist, .local-build, .smoke-build.
